# Prime Auto Care — one-page website

This folder contains the mobile-first public website for Prime Auto Care, Fulwadi, Surat.

## Included
- Responsive one-page layout using the Prime Auto Care black-and-gold identity.
- Services, address, business hours and contact details.
- WhatsApp contact button using the selected business number (+91 77779 70261).
- Google Business Profile link supplied by the owner.
- Google review link already used by the current WashDesk app, shown as an optional feedback link.
- LocalBusiness structured data.

## Publish with GitHub Pages
1. Merge the website pull request into `main`.
2. In GitHub, open **Settings → Pages** for this repository.
3. Under **Build and deployment**, choose **GitHub Actions** as the source.
4. The included workflow deploys the contents of this folder to GitHub Pages.
5. Once the deployment workflow succeeds, test the published URL:
   `https://zaid404sec.github.io/zaid404sec/website/`

## Add it to Google Business Profile
After the public URL works, sign in to the Google account that owns Prime Auto Care, open the Business Profile, choose **Edit profile → Contact → Website**, paste the public site URL and save. Verify the link in Search/Maps after Google processes the update.

## Owner review before publishing
Confirm the listed phone numbers, address, hours and the Google review URL. The supplied `share.google` URL is used for the Business Profile / Maps link. The direct review URL is the existing WashDesk default and remains replaceable in app settings if Google provides a different review link.
